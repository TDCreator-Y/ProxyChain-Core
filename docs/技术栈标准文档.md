# 🌐 全平台级联代理客户端 (Proxy Chain) 技术栈标准文档

## 1. 架构核心思想：彻底解耦

本项目采用 “核心驱动（Rust） + 表现层（Flutter）” 的彻底解耦架构。前端 UI 不处理任何网络底层逻辑，底层 Core 也不涉及任何界面渲染。

两者通过高效的 FFI (Foreign Function Interface) 进行强类型、低延迟的通信。

## 2. 前端展示层 (UI & UX) - Flutter

利用一套代码实现全平台（Windows, macOS, Linux, iOS, Android）的极致原生体验。

- 框架语言：Flutter 3.x / Dart 3.x (具备健全的空安全 Null-Safety)
- 状态管理：Riverpod (推荐 flutter_riverpod)
  - 理由：对异步流（Stream）支持极佳。代理软件需要高频渲染实时网速、日志和连接状态，Riverpod 的细粒度刷新机制能避免全局重绘造成的卡顿。
- 本地存储：Isar 或 Hive
  - 应用场景：本地持久化存储海量的节点数据、订阅链接列表、用户的个性化分流规则和配置选项。Isar 性能极高，适合存储结构化节点数据。
- 系统托盘/系统交互：
  - tray_manager (桌面端：系统托盘图标、右键菜单快捷切换节点)
  - window_manager (桌面端：控制窗口大小、隐藏到托盘、无边框设计)
- 路由管理：GoRouter
  - 理由：官方推荐，支持深层链接，结构清晰。

## 3. 底层核心层 (Proxy Core) - Rust

负责所有的网络接管、协议解析、加密解密和级联转发逻辑。

- 核心语言：Rust (Edition 2021)
  - 理由：无 GC（垃圾回收），内存占用极低（突破 iOS 15MB 限制），并发性能极致，内存安全。
- 异步运行时：Tokio
  - 应用场景：处理成千上万的并发网络连接 (TCP/UDP)。
- 网络与协议库：
  - 基础网络：tokio-net, hyper
  - 代理协议生态：可以直接集成或参考开源的 Rust 代理实现（如 shadowsocks-rust 的核心库）。
- 系统网卡接管 (TUN)：
  - 桌面端：tun crate (Linux/macOS) / wintun bindings (Windows)
  - 移动端：提供 FD (File Descriptor) 接口供 iOS NetworkExtension 和 Android VpnService 注入。
- 序列化与反序列化：Serde (serde, serde_json, serde_yaml)
  - 应用场景：解析机场订阅下发的 YAML/JSON 配置文件，以及与前端进行数据交互。
- 日志系统：Tracing (tracing, tracing-subscriber)
  - 应用场景：提供异步友好的结构化日志，方便排错，并通过 FFI 将日志流实时推送到 Flutter 界面。

## 4. 跨语言通信桥梁 (The Bridge)

这是连接 Flutter 和 Rust 的关键，极其不建议手写 C 风格的 FFI，容易出错。

- 核心框架：Flutter Rust Bridge (FRB v2)
- 理由：这是目前 Flutter + Rust 生态最完美的解决方案。
- 工作原理：你只需要在 Rust 中写好普通函数（比如 pub fn start_proxy(entry: Node, exit: Node)），FRB 会自动为你生成对应的 Dart 类和调用方法，完全抹平类型转换（如 String, List, Struct）和异步调用的鸿沟。
- 对 Trae 极度友好：避免了让 AI 编写容易内存泄漏的手动指针转换代码。

## 5. 项目工程化结构 (Monorepo 推荐)

为了让 AI 助手 (Trae) 更好地理解全局上下文，建议采用如下的单一仓库结构：

```text
proxy-chain-app/
├── Cargo.toml                  # 整个工作区的 Rust 配置
├── rust_core/                  # 【Rust 底层逻辑】
│   ├── Cargo.toml
│   ├── src/
│   │   ├── api.rs              # FRB 暴露给前端的公共接口 (给 Trae 的重点)
│   │   ├── proxy_engine/       # 代理链转发实现 (TCP/UDP relay)
│   │   ├── config_parser/      # 订阅解析 (YAML/Base64)
│   │   └── tun_device/         # 虚拟网卡驱动操作
│   └── build.rs
├── flutter_ui/                 # 【Flutter 界面逻辑】
│   ├── pubspec.yaml
│   ├── lib/
│   │   ├── main.dart
│   │   ├── src/rust/           # FRB 自动生成的 Dart 绑定代码 (不要手动改)
│   │   ├── providers/          # Riverpod 状态 (网速、连接状态)
│   │   ├── models/             # Dart 数据模型 (Node, Config)
│   │   └── views/              # 具体的界面 UI (Dashboard, Settings)
├── scripts/                    # 自动化编译与打包脚本
└── .gitignore
```

## 6. AI (Trae) 辅助开发依赖表指引

当你让 Trae 初始化项目时，可以让它直接安装以下核心依赖：

### Rust (rust_core/Cargo.toml)

```toml
[dependencies]
tokio = { version = "1", features = ["full"] }
serde = { version = "1", features = ["derive"] }
serde_json = "1"
serde_yaml = "0.9"
tracing = "0.1"
flutter_rust_bridge = "2.0.0-dev.x" # 根据最新版本定
```

### Flutter (flutter_ui/pubspec.yaml)

```yaml
dependencies:
  flutter:
    sdk: flutter
  flutter_riverpod: ^2.5.1
  go_router: ^13.2.0
  isar: ^3.1.0
  isar_flutter_libs: ^3.1.0
  flutter_rust_bridge: ^2.0.0-dev.x # 对应 Rust 端版本
```
